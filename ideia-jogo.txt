Para um **Projeto Integrador de ADS**, eu recomendaria **um jogo estilo Brotato** na maioria dos casos.

Vamos comparar pensando no que o professor provavelmente vai avaliar.

| Critério                    | Stardew Valley              | Brotato         |
| --------------------------- | --------------------------- | --------------- |
| Complexidade                | Muito alta                  | Média           |
| Tempo de desenvolvimento    | Longo                       | Curto           |
| Quantidade de sistemas      | Muitas mecânicas diferentes | Menos mecânicas |
| Facilidade de concluir      | Difícil                     | Mais fácil      |
| Demonstração de programação | Boa                         | Muito boa       |
| Risco de projeto incompleto | Alto                        | Baixo           |

## Se fizer um Stardew Valley

Você precisará desenvolver:

* Sistema de inventário
* Plantio
* Crescimento de culturas
* Economia
* NPCs
* Diálogos
* Relacionamentos
* Ciclo de dia/noite
* Salvar progresso
* Mapas maiores
* IA de NPCs
* Loja

Mesmo uma versão simplificada pode ficar grande demais para um semestre.

---

## Se fizer um Brotato

Você pode focar mais na parte técnica:

### Mecânicas principais

* Movimento do personagem
* Inimigos surgindo em ondas
* IA simples
* Sistema de armas
* Upgrades
* Progressão
* Loja entre rodadas
* Estatísticas do jogador

### APIs e banco de dados

Você ainda consegue usar:

* Login/JWT
* Ranking online
* Salvamento de progresso
* Estatísticas dos jogadores
* Leaderboard
* Discord Rich Presence

Isso costuma impressionar mais porque mostra integração entre jogo e sistemas web.

---

## Uma ideia interessante

### "Brotato Online"

* Login com JWT
* Ranking global
* Estatísticas armazenadas em banco
* Histórico de partidas
* Conquistas
* Discord Rich Presence

Relatórios:

* Jogador com maior pontuação
* Arma mais utilizada
* Inimigo mais derrotado
* Tempo médio de sobrevivência

Isso conversa muito bem com os conteúdos de ADS:

* Banco de dados
* APIs REST
* Autenticação
* Estatística
* Relatórios
* Consumo de APIs

## O que eu faria

Se o objetivo é **tirar uma nota alta e garantir que o projeto fique pronto**, escolheria um **roguelike survivor estilo Brotato/Vampire Survivors**.

Se o objetivo é **ter um jogo mais bonito e divertido para portfólio**, escolheria o Stardew Valley simplificado.

Para um Projeto Integrador, geralmente vale mais um projeto **100% concluído e polido** do que um Stardew Valley que termina com metade das funcionalidades planejadas.






















Projeto Integrador – Farm Game

-- Descrição do Projeto

Desenvolvimento de um jogo de simulação RPG 2D com visão top-down, inspirado em jogos como Stardew Valley.
O jogador assume o papel de um fazendeiro que deve administrar sua plantação, interagir com moradores da cidade e evoluir sua fazenda ao longo dos dias. O progresso é salvo online através de uma API REST, permitindo autenticação e persistência dos dados do jogador.

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Objetivo

Desenvolver uma aplicação completa composta por:

- Cliente do jogo desenvolvido em GameMaker
- API REST para gerenciamento de usuários e progresso
- Banco de dados para armazenamento das informações
- Integração com APIs externas
- Sistema de autenticação JWT

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Funcionalidades Principais

-- Sistema de Jogador
  - Cadastro de usuário
  - Login com JWT
  - Salvamento de progresso
  - Carregamento de partidas

-- Sistema de Agricultura
- Compra de sementes
  Tipos iniciais:
    Batata (crescimento rápido)
    Tomate (crescimento médio)
    cenoura (crescimento lento)

- Cultivo
  Plantar sementes
  Regar plantações
  Crescimento por passagem de dias
  Colheita

- Economia
  Venda dos produtos colhidos
  Acúmulo de moedas
  Compra de novas sementes

- Sistema de Tempo
  Ciclo de dias
  Dormir para avançar o tempo
  Crescimento das plantações baseado em dias

- Sistema de NPCs
  Interação com moradores
  Diálogos simples
  Escolhas de relacionamento
  Evolução do nível de amizade

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Sistema de Progressão

O jogador evoluirá através da agricultura, relacionamentos e tempo de jogo

Agricultura
  Quantidade de colheitas realizadas
  Dinheiro acumulado

Relacionamentos
  Nível de amizade com NPCs

Tempo de Jogo
  Dias sobrevividos

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Condição de Vitória

O jogador desbloqueia o final do jogo após atingir 100 dias jogados, conseguir ter amizade máxima com todos os NPCs e obter certa quantidade de dinheiro

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Diferenciais do Projeto

- Integração com API de Clima
  Utilização da API do OpenWeather para obter clima real
    Chuva real: plantações recebem irrigação automática
    Clima seco: maior necessidade de regar

- Sistema de Salvamento Online
  Dados armazenados em banco de dados
  Recuperação do progresso em qualquer dispositivo

- Discord Rich Presence
  Exibir no Discord informações como:
    Dia atual
    Dinheiro
    Tempo de jogo

- Tradução Automática
  Permitir troca de idioma utilizando API de tradução.

- Notificações por E-mail
  Enviar e-mail de boas-vindas
  Enviar e-mail para recuperação de senha

---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Relatórios e Dashboard

Fazer talvez um painel administrativo na WEB

- Relatórios do Sistema
  Quantidade de usuários cadastrados.
  Dias jogados por usuário.
  Total de colheitas realizadas.
  Produto mais vendido.
  Ranking dos jogadores mais ricos.
