-- Projeto Integrador - Hamstorm (Estilo Brotato)
-------------------------------------------------------------------------------------------------------------------------------------------------------------------
-- jogo de tiro twin-stick em arena estilo roguelite top-down
-------------------------------------------------------------------------------------------------------------------------------------------------------------------
-- tem um hamster que enfrenta monstos em ondas cronometradas
-- com o objetivo de sobreviver as ondas, coletar recursos, aprimorar seu personagem e derrotar o chefão na onda final
-------------------------------------------------------------------------------------------------------------------------------------------------------------------

Jogos de tiro twin-stick (dois analógicos) é um subgênero de jogos de tiro onde a mecânica de movimento do personagem e a mira são controladas de forma independente usando dois sticks de um controle
  analógico esquerdo ou WASD (movimento)
  analógico direito ou mouse (direção disparos)

Roguelite é subgênero de jogos focado na rejogabilidade, com mortes permanentes e fases geradas aleatoriamente
  São desbloqueados conforme vai jogando:
    - dificuldade da partida
    - personagens novos (ao concluir desafios durante a partida)
    - itens novos

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Tecnologias
  front-end do jogo: GameMaker Studio 2 com GML (GameMaker Language)
  front-end da web: HTML, CSS e Boostrap
  back-end: Node + Express com JWT (pra segurança)
  banco de dados: PostgreSQL

-- Jogabilidade do Brotato (adaptar)
  jogador controla o personagem e os tiros são disparados automaticamente nos inimigos em seu campo de visão
  dura 20 ondas, em cada uma o jogador deve fugir e/ou matar os inimigos, desviar dos projéteis deles e coletar os materiais dropados por eles
  pode equipar até 6 armas, podendo ser melhoradas para causar mais dano ou ter efeitos especiais
  tem uma loja entre uma onda e outra, onde gasta os materiais coletados para:
    comprar novas armas (fundir umas com as outras pra melhorar)
    itens de cura
    melhorias de atributos (vida, armadura, velocidade de ataque, ...)
    perks (vantagens passivas, tipo ter 3 armas primitivas ganha +15 de vida máxima)
  a maioria dos itens tem vantagens e desvantagens (para equilibrar)
  ao derrotar os inimigos ganha pontos de experiência para subir de nível, cada vez que sobe pode escolher opções de atributos para melhorar o personagem
  tem diversos personagens diferentes, cada um com suas vantagens e desvantagens
  o jogador deve então escolher quais armas usar que garantirá vantagem para o personagem escolhido

-- Mecânicas principais
  Movimento do personagem
  Inimigos surgindo em ondas
  IA simples
  Sistema de armas
  Upgrades
  Progressão
  Loja entre rodadas
  Estatísticas do jogador

-- APIs e banco de dados
  Login/JWT
  Ranking online
  Salvamento de progresso
  Estatísticas dos jogadores
  Leaderboard
  Discord Rich Presence

-- Relatórios:
  Jogador com maior pontuação
  Arma mais utilizada
  Inimigos mais derrotados (bom para balancear o jogo)
  Tempo médio de sobrevivência (bom pra balancear também)

-- Projeto Integrador – Estilo Stardew Valley
-------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Descrição do Projeto

Desenvolvimento de um jogo de simulação RPG 2D com visão top-down, inspirado em jogos como Stardew Valley.
O jogador assume o papel de um fazendeiro que deve administrar sua plantação, interagir com moradores da cidade e evoluir sua fazenda ao longo dos dias. O progresso é salvo online através de uma API REST, permitindo autenticação e persistência dos dados do jogador.

------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Objetivo

Desenvolver uma aplicação completa composta por:

- Cliente do jogo desenvolvido em GameMaker
- API REST para gerenciamento de usuários e progresso
- Banco de dados para armazenamento das informações
- Integração com APIs externas
- Sistema de autenticação JWT

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Funcionalidades Principais

-- Sistema de Jogador
  - Cadastro de usuário
  - Login com JWT
  - Salvamento de progresso
  - Carregamento de partidas

-- Sistema de Agricultura
- Compra de sementes
  Tipos iniciais:
    Batata (crescimento rápido)
    Tomate (crescimento médio)
    cenoura (crescimento lento)

- Cultivo
  Plantar sementes
  Regar plantações
  Crescimento por passagem de dias
  Colheita

- Economia
  Venda dos produtos colhidos
  Acúmulo de moedas
  Compra de novas sementes

- Sistema de Tempo
  Ciclo de dias
  Dormir para avançar o tempo
  Crescimento das plantações baseado em dias

- Sistema de NPCs
  Interação com moradores
  Diálogos simples
  Escolhas de relacionamento
  Evolução do nível de amizade

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Sistema de Progressão

O jogador evoluirá através da agricultura, relacionamentos e tempo de jogo

Agricultura
  Quantidade de colheitas realizadas
  Dinheiro acumulado

Relacionamentos
  Nível de amizade com NPCs

Tempo de Jogo
  Dias sobrevividos

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Condição de Vitória

O jogador desbloqueia o final do jogo após atingir 100 dias jogados, conseguir ter amizade máxima com todos os NPCs e obter certa quantidade de dinheiro

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

-- Diferenciais do Projeto

- Integração com API de Clima
  Utilização da API do OpenWeather para obter clima real
    Chuva real: plantações recebem irrigação automática
    Clima seco: maior necessidade de regar

- Sistema de Salvamento Online
  Dados armazenados em banco de dados
  Recuperação do progresso em qualquer dispositivo

- Discord Rich Presence
  Exibir no Discord informações como:
    Dia atual
    Dinheiro
    Tempo de jogo

- Tradução Automática
  Permitir troca de idioma utilizando API de tradução.

- Notificações por E-mail
  Enviar e-mail de boas-vindas
  Enviar e-mail para recuperação de senha

-------------------------------------------------------------------------------------------------------------------------------------------------------------------

  Quantidade de usuários cadastrados.

  Ranking dos jogadores mais ricos.
