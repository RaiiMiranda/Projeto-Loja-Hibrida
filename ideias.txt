----------------------------------------------------------------------------------------------------------------------------------------------------------
-- Ideias de Projeto:
----------------------------------------------------------------------------------------------------------------------------------------------------------

Pergunta: Qual seria o fluxo principal, suas funcionalidades e regras de negócio?

1) Sistema para ensino de programação/computacao para criancas daria pra ser utilizado na Maple Bear, algo parecido com o Scratch
  - cadastro de alunos (nomes nao podem repetir)
  - cadastro de professores (e-mails nao podem repetir)
  - cadastro de turmas (inserir alunos, professores, exercicios)


3) Sistema para fazer review de cinema, livros, arte
  - mas o que faria ele ser melhor dos que ja tem?


4) Sistema de troca de colecionáveis (link ideia: https://colnect.com/br/stamps/currencies) (PDV)
  Funcionalidades  
    Cadastro de Colecionadores
    Cadastro de Colecionaveis
    Filtro
    Lista de desejo (se eu tenho A e quero B, e o outro tem B e quer A, o sistema avisa)
    "Carrinho" que na verdade é um ambiente que ocorre a troca (da pra fazer um style como o persona na hora de combate)

  Diferencial
    Trazer a ideia de RPG
    Gamificação (ganha medalhas se concluir uma coleção, pode evoluir seu perfil)
    Cadastro de colecionador (país de origem, perfil)


5) Sistema de Agendamento para Clínicas ou Profissionais Autônomos
  Problema real: agenda no WhatsApp vira bagunça.

  Funcionalidades
    Cadastro de profissionais
    Agenda com horários disponíveis
    Confirmação automática
    Painel administrativo
    Histórico de atendimentos

  Diferencial
    Envio de e-mail automático
    Calendário interativo
    Controle de conflitos de horário
    Área do cliente


6) Plataforma para Gestão de Condomínios
  (ver com meu condominio)

  Funcionalidades
    Cadastro de moradores
    Cadastro de visitante
    Controle de entrada e saída de visitantes
    Reserva de áreas comuns
    Avisos do síndico
    Controle de boletos
    Registro de ocorrências
  
  Diferencial
    Sistema de permissões
    Upload de documentos
    Notificações
    Dashboard administrativo


7) Plataforma de Organização de Estudos
  Funcionalidades
    Cadastro de usuário
    Cadastro de matérias
    Planejamento semanal
    Controle de horas estudadas
    Sistema de metas
    Checklist de tarefas

  Diferencial
    Estatísticas de produtividade
    Gamificação (pontuação, níveis, linha do tempo)
      Fazer algo tipo o app Arvore, que o tanto que voce lê ganha sementes para plantar e criar uma horta
      Dá pra fazer algo tipo Jardim de Cristais
    Ranking entre usuários
    Ser um app instalável
